# Tools

If you have proficiency with a tool, add your Proficiency Bonus to any ability check you make that uses the tool. If you also have proficiency in a skill used with that check, you have Advantage on the check too.

### Artisan's Tools

Each requires a separate proficiency. Each listing shows cost, weight, the relevant ability, what you can do with a Utilize action, and what items you can craft with it.
