# Spell Slots Reference

Spell slots are the resource spellcasting classes expend to cast leveled spells. Different classes have different slot progressions.

---

Warlocks use Pact Magic, not standard Spellcasting. All spell slots are the same level (the Slot Level column). Slots recover on a Short Rest or Long Rest. At levels 11–20, Mystic Arcanum grants one use of a specific high-level spell per Long Rest, separate from Pact Magic slots.

## Multiclass Spellcaster Spell Slots

When multiclassing, combine your spellcasting levels using this formula:
- Full caster classes (Bard, Cleric, Druid, Sorcerer, Wizard): add all levels
- Half caster classes (Paladin, Ranger): add half your levels (round up)
- Warlock Pact Magic slots are tracked separately and can be used to cast spells from other classes
