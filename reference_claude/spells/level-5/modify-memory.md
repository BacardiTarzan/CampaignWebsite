# MODIFY MEMORY
**Level:** 5
**School:** Enchantment
**Classes:** Bard, Wizard
**Casting Time:** Action
**Range:** 30 feet
**Components:** V, S
**Duration:** Concentration, up to 1 minute

You attempt to reshape another creature's memories. One creature that you can see within range makes a Wisdom saving throw. If you are fighting the creature, it has Advantage on the save. On a failed save, the target has the Charmed condition for the duration. While Charmed, the target also has the Incapacitated condition and is unaware of its surroundings, though it can hear you. If it takes any damage or is targeted by another spell, this spell ends, and no memories are modified.

While this charm lasts, you can affect the target's memory of an event that it experienced within the last 24 hours and that lasted no more than 10 minutes. You can permanently eliminate all memory of the event, allow the target to recall the event with perfect clarity, change its memory of the event's details, or create a memory of some other event.

**Using a Higher-Level Spell Slot.** You can alter the target's memories of an event that took place up to 7 days ago (level 6 slot), 30 days ago (level 7 slot), 365 days ago (level 8 slot), or any time in the creature's past (level 9 slot).
