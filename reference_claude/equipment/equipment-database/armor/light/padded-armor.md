# Padded Armor

**Type:** Light Armor  
**Armor Class (AC):** 11 + Dexterity modifier  
**Weight:** 8 lb.  
**Cost:** 5 GP  
**Don/Doff Time:** 1 minute

## Properties
- Disadvantage on Stealth checks

## Description
Armor made from layers of cloth and batting, the cheapest armor available. Provides basic protection but hinders stealthy movement.
