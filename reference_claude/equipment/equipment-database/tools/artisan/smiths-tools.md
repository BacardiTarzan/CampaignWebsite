# Smith's Tools

**Cost:** 20 GP  
**Weight:** 8 lb.  

## Ability
Strength

## Utilize (DC 20)
- Pry open a door or container

## Craft
- Any Melee weapon (except Club, Greatclub, Quarterstaff, and Whip)
- Medium armor (except Hide)
- Heavy armor
- Ball Bearings
- Bucket
- Caltrops
- Chain
- Crowbar
- Firearm Bullets
- Grappling Hook
- Iron Pot
- Iron Spikes
- Sling Bullets

## Description
Hammer, anvil, tongs, and other tools for smithing and metalworking.
