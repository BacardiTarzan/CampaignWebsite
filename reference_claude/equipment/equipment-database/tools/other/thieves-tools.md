# Thieves' Tools

**Cost:** 25 GP  
**Weight:** 1 lb.  

## Ability
Dexterity

## Utilize
- Pick a lock (DC 15)
- Disarm a trap (DC 15)

## Description
Lockpicks, small mirrors, tension wrenches, and other tools for opening locks and disarming traps. Essential for rogues and adventurers who need to access secured areas.
